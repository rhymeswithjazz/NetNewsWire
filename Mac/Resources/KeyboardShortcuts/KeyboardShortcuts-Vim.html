Keyboard Shortcuts — Vim Style

Vim Style reserves h, j, k, and l for navigation. Arrow-key and other non-conflicting standard shortcuts remain available.

Subscriptions…
Select previous or next subscriptionk / j
Collapse selected folderh
Expand folder or move to headlinesl
Headlines…
Select previous or next articlek / j
Move to subscriptions or articleh / l
Article…
Scroll up or downk / j
Move to headlinesh

Space and Shift-Space scroll by page, Return opens the article, and Command-based menu shortcuts continue to work normally.
